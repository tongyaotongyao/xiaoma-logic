# 左键抚摸误命中（隐藏小马组件仍可被点到）

> 状态：**已修复**。改动集中在 `Source/XiaomaLogic/XiaomaBoardActor.cpp`，未动抚摸玩法本身。

## 现象

- 棋盘格子上没有小马时，点下去也会触发「轻抚」，好感度照样 +1。
- 有时点下去又完全没反应（尤其点格子边缘）。

## 结论

「轻抚小马」本身是协作者**刻意设计**的玩法，不是误加的功能：

- `AXiaomaHUDWidget::BuildGameHUD` 的说明里有「左键轻抚小马」；
- 每关每种颜色只能加一次好感（`PettedMask` 位掩码，随续局存进 `ActivePettedMask`）；
- 第二次抚摸会换成另一句台词「小马开心地跳了一下」；
- 通关另有 +5 好感（`XiaomaGameMode.cpp` 的结算分支）。

但**点空格子也涨好感是 bug**。

## 根因

1. `AXiaomaBoardActor::BuildBoard` 给 36 个格子每格都建了一个 `Ponies[Index]` 静态网格组件，
   并且一律 `SetCollisionResponseToChannel(ECC_Visibility, ECR_Block)`。
2. `RefreshBoard` 用 `Ponies[Index]->SetVisibility(bShowPony)` 切换有没有小马。
   `UPrimitiveComponent` 没有重写 `SetVisibility`，所以它**只影响渲染，不影响碰撞** —— 隐藏的小马照样挡住射线。
3. `AXiaomaPlayerController::OnLeftClick` 拿到命中组件后调 `AXiaomaBoardActor::FindPonyColour`，
   而 `FindPonyColour` 遍历棋盘小马时**只比较组件指针，不判断可见性**：

   ```cpp
   for (int32 Index = 0; Index < Ponies.Num(); ++Index)
   {
       if (Ponies[Index] == Component && RegionAtCell.IsValidIndex(Index))
       {
           return RegionAtCell[Index];   // 隐藏的也算
       }
   }
   ```

   待命区那一段有同样的问题（已放到棋盘上的那匹马，其待命区副本也能被点到）。

4. 于是：点到小马模型的投影范围 → 命中隐藏组件 → 返回「该格颜色」→ `PetPony(Colour)` →
   这一色本关还没抚过就 +1 并存盘。

这也解释了「碰巧点到正确格子」的观感：只有点在格子中央（小马模型覆盖处）才命中 Pony 组件；
点在格子边缘命中的是 `Tiles[Index]`，`FindPonyColour` 返回 `INDEX_NONE`，于是什么也不发生。

存档里的佐证：某份存档 `Affection = 44`、`ActivePettedMask = 63`（6 位全满），即每关 6 点都被
「点格子」点满了。

## 修法（已实施，两条都做了）

1. `FindPonyColour` 两段循环都加上可见性判断：

   ```cpp
   if (StandbyPonies[Colour] == Component && StandbyPonies[Colour]->IsVisible()) { ... }
   if (Ponies[Index] == Component && Ponies[Index]->IsVisible() && RegionAtCell.IsValidIndex(Index)) { ... }
   ```

   点空格子不再有任何反应；只有看得见的小马才会被认定为「摸到了」。

2. 新增文件内辅助函数 `SetPonyVisible(Pony, bVisible)`，把显示与碰撞绑在一起：

   ```cpp
   Pony->SetVisibility(bVisible);
   Pony->SetCollisionEnabled(bVisible ? ECollisionEnabled::QueryOnly : ECollisionEnabled::NoCollision);
   ```

   棋盘小马、待命区小马（含飞入/请回动画的起止两端、以及 Tick 里飞行结束的那一刻）全部改走这个函数，
   不再留裸的 `SetVisibility` 调用。隐藏组件彻底不挡射线，以后给格子加点击交互也不会被幽灵碰撞体拦住。

两条是**互为保险**的关系：只做第 2 条，射线就不会命中隐藏组件；只做第 1 条，即使命中了也不会误判。
两条一起做，任何一条将来被改坏都还有另一条兜着。

## 验证

- 编译通过（`XiaomaLogicEditor Win64 Development`），`XiaomaLogic.Puzzle.AllLevels` 通过。
- 真机待验收：点空格子应完全无反应；点待命区或棋盘上可见的小马仍会跳一下；同一颜色第二次抚摸只换台词不加好感。

## 附带发现

`AXiaomaGameMode::PetPony` 里每次首次抚摸都会 `SaveProgress()`。每关最多 6 次，开销可以接受，
但如果以后加上抚摸动画/音效，要注意别让它变成高频写盘。
